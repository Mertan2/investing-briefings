# Daily Investing Briefings

Automated daily portfolio review and 10 fresh buy targets, generated by a Claude Code scheduled task.

**Live site:** *(set up GitHub Pages — see `GITHUB-SETUP.md`)*

## Layout

- `portfolio/my-portofilo.md` — current holdings (hand-edited).
- `briefings/YYYY-MM-DD.html` — daily HTML briefing (portfolio review + 10 targets + actions).
- `briefings/index.html` — landing page that lists every briefing.
- `buy-targets/YYYY-MM-DD.md` — that day's 10 working buy ideas + watch-list, used for day-over-day diff.
- `buy-targets/latest.md` — pointer to the most recent dated targets file.

## How it works

A scheduled task fires daily. Each run:

1. Reads the portfolio file to confirm holdings.
2. Reads yesterday's targets to compare against.
3. Web-researches each holding (price, news, earnings, analyst view).
4. Web-researches each prior target and decides **keep / downgrade / replace** — always ending with exactly 10.
5. Writes a dated HTML briefing and a new targets file.
6. Updates `latest.md` pointer.

## Serving

Files are static HTML with inline CSS — no build step. Once GitHub Pages is enabled on this repo (Settings → Pages → Deploy from branch → `main` / `/`), the site is reachable at `https://<your-github-username>.github.io/<repo-name>/`.

Setup instructions: see [GITHUB-SETUP.md](./GITHUB-SETUP.md).

## Disclaimer

These briefings are automated research, not financial advice. All prices and analyst targets reflect data captured at generation time and can be stale. Verify with your broker before any trade.
